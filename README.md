A one-line weather forecast for Drizzleford, a city that isn't.

## Entry

> In Drizzleford, expect rain, then more rain, then a brief apology from the rain, then rain.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes `entry.txt` (UTF-8, one line, no trailing newline) and verifies it on disk.
